# DevQuest: The Web Matrix Chronicles (`fullstack-learning-guide`)

An interactive **Next.js 15 + TypeScript + Tailwind CSS RPG Learning Platform** paired with a comprehensive 13-module **Full-Stack Web Development Curriculum**.

> 📖 **Looking for gameplay guides & instructions?** See the full [**Official Game Manual (`GAME_MANUAL.md`)**](GAME_MANUAL.md) for complete details on campaign realms, boss battles, IDE shortcuts, RPG progression, and skill tree perks.

## Quick Start

```bash
# Start the interactive Next.js development server
npm run dev

# Run Vitest unit & solution verification tests
npm test

# Run full validation gate (TypeScript strict check + Vitest + Next.js production build)
npm run validate
```

Open [http://localhost:3000](http://localhost:3000) to enter **The Web Matrix**.

## Key Features
- **12 Campaign Realms**: Progress through HTML, CSS, JavaScript, TypeScript, React/Next.js, Node.js Backend, PostgreSQL/Databases, DevOps/Docker, Testing/TDD, CS & System Design, Web Security, and Capstone Architecture.
- **Interactive Quest Coding Workspace**: Dual-pane coding mission briefing, live preview sandbox, interactive concept visualizers for every realm, and instant test runner verification.
- **Multi-Phase Boss Battles**: Turn-based debugging encounters against 12 custom SVG cybernetic Bug Guardians (*The Overflow Hydra*, *The Callback Kraken*, *The Any-Demon*, *The Null Void*, and more).
- **Cybernetic Skill Tree & Trophy Room**: Earn XP, level up, unlock passive combat/XP perks, and collect milestone badges.
- **Curriculum Knowledge Vault**: Built-in interactive reader for all 13 curriculum reference guides (`00-curriculum-overview.md` through `12-roadmap-capstone-and-resources.md`).
- **Byte (AI Cybernetic Familiar)**: Global companion providing contextual tips, trivia, and realm guidance.
